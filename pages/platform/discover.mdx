Discover is the front door of Liport. Every token shows up the moment it deploys. No manual listing. No approval queue. No curation committee.

## Filters

Each filter is a different view of the same set of tokens.

| Filter | What it shows |
| --- | --- |
| **New** | Just-launched tokens, sorted by deployment time. |
| **Trending** | Highest combined activity over a rolling window. |
| **Featured** | Picks surfaced by the platform. |
| **Explore** | A spread across activity levels. |
| **Movers** | Biggest price swings. |
| **Market Cap** | Sorted by market cap. |
| **Recommended** | Tokens picked from platform signals. |
| **Last Traded** | Sorted by most recent trade. |

## Time window

Where it applies, the filter takes a time window:

- `5m` for the last 5 minutes
- `1h` for the last hour
- `6h` for the last 6 hours
- `24h` for the last 24 hours

## Graduated only

The `migratedOnly` toggle (independent of the filter) limits the feed to tokens that have graduated to Raydium CPMM. Useful when you want deeper liquidity and standard AMM behaviour.

## The coin card

Each card shows the things you need at a glance:

- Logo, name, symbol, copy-CA button
- Current price and 24h change
- Market cap
- Graduation progress (for tokens still on the curve)
- Creator

Click anywhere on the card to open the full [Token Page](/platform/token-page).

## Search

The top-bar search covers the whole platform. It matches across:

- **Coin name or ticker.** Typing `pepe` returns any coin whose name or symbol matches. Exact ticker matches rank above partial name matches.
- **Mint address.** Paste a full Solana mint address to jump straight to the coin.
- **Wallet address.** Paste a Solana wallet address to jump to that profile.

Search only covers Liport data. A coin on Solana that did not launch through Liport will not show up.

## Favourites

Every card has a star icon. Click it to save the token. Click again to remove it.

You need to be signed in with a wallet to use favourites. The list is tied to your wallet address, so it syncs to any device you connect with.

Open **Favourites** from the top nav to see every coin you have starred in one grid, with the same card format as Discover. Favourites are private and never emit a public event.
